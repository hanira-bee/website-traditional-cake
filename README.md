# 🍰 Traditional Cake Website 

A **traditional cake website built with HTML, CSS, and JavaScript**, a college project for semester final assignment.

start: January 18, 2025
finish: Mei 04, 2025

update: September 13, 2026

## 📄 Requirements
- HTML5
- CSS3
- JavaScript

## 🔖 Features
- Users can view the recipe list
- Select recipe categories (steamed cakes or cookies)
- View recommendations for traditional cake shops
- See ingredients and preparation steps
- User reviews (the data could not be saved)
- Social media page
- About page
- Language --> Indonesia (possibly will add english)
